# Semana 01 — Exercícios Básicos em Python

Primeiros exercícios de lógica de programação em Python, cobrindo entrada e
saída de dados, operadores aritméticos, condicionais simples e formatação com
f-strings.

## Estrutura

sem-1/
├── calc-tro.py
├── conv-temp.py
├── desconto.py
├── inver.py
├── media-notas.py
└── par-im.py

## Arquivos

| Arquivo | Descrição |
|---|---|
| `calc-tro.py` | Calcula o troco de uma compra. |
| `conv-temp.py` | Converte temperatura entre Celsius e Fahrenheit. |
| `desconto.py` | Calcula o valor final de um produto com desconto. |
| `inver.py` | Inverte os dígitos de um número. |
| `media-notas.py` | Calcula a média de notas de um aluno. |
| `par-im.py` | Verifica se um número é par ou ímpar. |

## Como executar

    python sem-1/calc-tro.py
    python sem-1/conv-temp.py
    python sem-1/desconto.py
    python sem-1/inver.py
    python sem-1/media-notas.py
    python sem-1/par-im.py

## Conceitos aplicados

| Conceito | Onde aparece |
|---|---|
| `input()` | Todos os scripts |
| `print()` com f-string | Todos os scripts |
| Operadores aritméticos | `calc-tro`, `conv-temp`, `desconto`, `inver`, `media-notas` |
| Condicional `if` / `else` | `par-im` |
| Conversão de tipos (`int`, `float`) | Todos os scripts |
| Nomes descritivos (PEP 8) | Todos os scripts |
